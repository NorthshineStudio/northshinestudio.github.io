Featured Unity Tool

HexMap Painter for Unity

HexMap Painter is a Unity editor tool for painting hex-based maps directly in the Scene View. It is designed for fast level blockout, layered tile placement, overlay placement, and a practical editor workflow.

  • Paint hex tiles directly in Unity Scene View
  • Layer-based placement for height variation
  • Overlay placement for props, buildings, and decorations
  • Rotation shortcuts and prefab selection tools
  • Replacement preview and erasing workflow
  • Useful for strategy maps, RPG maps, board-game-style maps, and level prototyping
